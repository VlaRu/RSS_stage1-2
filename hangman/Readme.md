# Hangman 

## Description:

[Hangman](<https://en.wikipedia.org/wiki/Hangman_(game)>) is a classic word game in which you must find the correct answer by guessing letters one at a time.

## Features

- All elements of html was ganarated in DOM with usefull js
- Responsive/adaptive UI from 1440px to 360px viewport
- The user can play the game both by using the virtual keyboard and physical
- When the letter is correct, it appears instead of the corresponding underscore. If the letter repeats in the word, all corresponding underscores replaced by it
- When the letter is incorrect:
   - the incorrect guesses counter is updated
   - a body part is added to the gallows
 - The clicked/pressed letter is disabled
